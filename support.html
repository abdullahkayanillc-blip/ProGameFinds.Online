Amazon Associates Customer Service

For Amazon Associates account status, application or final-acceptance questions, tracking IDs, payments, programme policies or Creators API access, use the official Amazon Associates Contact Us form for the marketplace where the Associates account is registered. ProGameFinds is an independent website and cannot view, change or approve an Amazon account.

Open Amazon.com Associates Contact Us

Amazon's Creators API support guide describes this contact process:

  1. Open the relevant Amazon Associates site and choose Help, then Contact Us. Amazon says signing in is not mandatory to open this contact route.
  2. For a Creators API technical question, choose Creators API from the Subject menu.
  3. Explain the use case and issue. For API errors, include a safe sample request, sample response, HTTP status and error message. Remove credentials, access tokens, customer data and other secrets.
  4. Review the details and select Send E-mail.

Response-time note: Amazon's guide says requests for final acceptance of an Associates account are reviewed by a specialist and that a response is expected within 3–4 days. This is not stated as a response-time guarantee for every support request.

Account-owner note: Amazon Associates account matters and Creators API registration or credential management should be handled by the adult legal account holder and, for API registration, the account's primary owner. Never publish or share API secrets.

Account-support guidance

External support links are not embedded on this website. For account-specific questions, use the support area of the marketplace account itself. ProGameFinds cannot access, change or approve another party's account.

PA-API 5 deprecation and Creators API

Amazon has deprecated Product Advertising API 5.0 (PA-API 5) and identifies the Creators API as its successor for product-catalog integrations. Amazon documents that continued PA-API 5 requests may return 403 Forbidden with an AccessDeniedException. Existing integrations should follow Amazon's migration guide instead of continuing to call the deprecated endpoint.

The Creators API is a REST API for product discovery and catalogue data. Its documented operations include SearchItems, GetItems, GetVariations and GetBrowseNodes.

Creators API access requirements

  • Be enrolled and fully accepted in Amazon Associates for the target marketplace.
  • Amazon's Creators API introduction currently lists at least 10 qualifying sales within the previous 30 days as an access prerequisite.
  • Register for API access in Associates Central. Amazon says only the primary account owner can register an application and create its credentials.
  • Use the correct marketplace and its assigned Partner Tag. API eligibility and access are controlled by Amazon.

For migration, Amazon documents a change from AWS Signature Version 4 authentication to OAuth 2.0. Existing PA-API AWS access-key credentials do not work with Creators API; new Creators API credentials are required. Keep secrets in a secure server-side secret store, never in public HTML, browser JavaScript or a public Git repository.
